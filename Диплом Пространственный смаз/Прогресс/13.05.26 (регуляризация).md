1. Следующий шаг - применение <u>регуляризации</u>
<u>Регуляризация</u> - решение некорректно поставленных (неустойчивых) задач путем задания дополнительной информации и/или разумных ограничений для стабилизации результатов.
В нашем случае некорректно поставленная задача - это инверсная фильтрация "в лоб", где мы делим на нулевые и околонулевые слагаемые спектра нашего ядра, в результате получаем заведомо негативные результаты.

Попробуем первый метод регуляризации - метод Тихонова.

2. Метод регуляризации Тихонова
Сейчас фокус на практику, поэтому кратко: 
Формула - не с потолка, а решение задачи минимизации квадратичного функционала Тихонова в частотной области. 
Она честно находит такое изображение (спектр его), которое дает минимум функционала при заданном λ и виде ограничивающего оператора.
При этом само полученное изображение не обязано быть оптимально близким к несмазанному само по себе - для этого важно выбрать ограничение задачи и его силу.
Сама формула:

F - спектр восстанавливаемого изображения - мы ищем;
H - спектр ядра смаза - мы задали;
G - спектр смазанного изображения;
λ - регуляризирующий (изменяемый) числовой параметр, задающий "силу" ограничения.

В записи самого функционала Тихонова есть стабилизирующий оператор (матрица/ядро), задающий тип накладываемого ограничения на решение задачи.
В формуле же восстановления его нет - это частный случай, когда стабилизатор представляет собой просто единичный оператор (не изменяющий объект, в записи функционала это будет видно) - <u>регуляризация по Тихонову нулевого порядка</u>.
Она "штрафует" только за высокую энергию пикселей восстанавливаемого изображения, 
в результате автоматически "отсекаются" варианты с огромными значениями яркости (которые естественно получаются при делении на околонулевые значения), поскольку они невыгодны для минимума функционала, а насколько эффективно он это делает - определяется параметром регуляризации.
