- Дополнена утилита load_image - возвращает два изображения, RGB трехканальное и в оттенках серого - двухканальное.
``` python
def load_image(filepath):
    """читает файл с диска и возвращает две картинки - RGB и grayscale."""
# превращение строки пути в удобный формат
    filepath = Path(filepath)

# imread требует строку
    img = cv2.imread(str(filepath))

    if img is None:
        print(f"Ошибка: не удалось прочитать {filepath}")
        return None
    
# конвертация из BGR в RGB
    img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
# конвертаця в grayscale (теперь img_gray.shape вернет два числа, а не три)
    img_gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

    return img_rgb, img_gray
```

- Задание ядра (функции рассеяния точки - PSF) линейного горизонтального смаза:

Сумма всех чисел в матрице должны быть равна 1 для сохранения общей яркости изображения (>1 - станет светлее, <1 - темнее) - нормировка;
Размер ядра = размеру изображения: перемножение матриц в частотной области;

*cv2.filter2D()* - двумерная пространственная свертка, реализующая разные эффекты, в том числе пространственный смаз. Она не создает ядро, а применяет то, которое ей дали, и не следит за нормализацией.
