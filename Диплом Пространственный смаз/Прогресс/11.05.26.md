- Переписана утилита show_image - теперь автоматически определяет, цветное ли трехканальное или иное изображение, и обработка только через matplotlib:

``` python
def show_image(img, title="Image"):
    """Показывает изображение. use_matplotlib=False → cv2.imshow"""
    # обработка теперь только через matplotlib
    if img is None:
        return
    # утилита сама определяет, что посылаем на вход:
    # три канала и uint_8 - обычные цветные изображения: конвертация BGR -> RGB
    # в оттенках серого или любые одноканальные (амплитудный спектр, e.g.) - вывод как есть
    # img.shape - кортеж, в котором хранятся размерности numpy-массива
    # при загрузке картинки через cv2.imread() - 3 числа: высота и ширина в пикселях
    # и глубина в цветовых каналах.
    # img.shape[2] - показывает количество цветовых каналов
    if len(img.shape) == 3 and img.shape[2] == 3 and img.dtype == np.uint8:
        # RGB-фото
        img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
        plt.imshow(img_rgb)
    else:
        # в оттенках серого (2D), спектр или float - что-то другое
        # явное задание цветовой схемы cmap через тернарный оператор
        cmap = 'gray' if len(img.shape) == 2 else None
        plt.imshow(img, cmap = cmap)
    plt.title(title)
    plt.axis("off")
    plt.tight_layout()
    plt.show()
```
