1. Добавил утилиты fast_blur и create_kernel:
``` python
def fast_blur(img, smear_length):
    """Возвращает изображение с горизонтальным смазом заданной длины"""
    kernel_small = np.ones((1, smear_length)) / smear_length
    blurred = cv2.filter2D(img, -1, kernel_small)
    return blurred

def create_kernel(img, smear_length):
    """Возвращает PSF горизонтального смаза для восстановления в частотной области"""
    rows, cols = img.shape
    kernel = np.zeros((rows, cols)) / smear_length
    center_row = rows // 2
    center_col = cols // 2
    half = smear_length // 2
    kernel[center_row, center_col - half: center_col + half + 1] = 1 / smear_length
    
    # подготовка к БПФ с помощью ifftshift - перемещение самого ядра в (0, 0)
    kernel = np.fft.ifftshift(kernel)

    return kernel
```

Возможно, дело в том, что cv2.filter2d делает пространственную свертку с зеркальным отражением краев, а БПФ-умножение производит в пространственной области циклическую свертку - изображение не отражается, а зацикливается.

Частотное восстановление соответствует циклической свертке в пространственной области. Если для задания модели смаза использовать другой способ, то мы не сможем полноценно оценивать эффективность самого метода восстановления, постоянно сталкиваясь с систематической погрешностью рассогласования методов задания и восстановления смаза.

Используем функцию scipy.signal.convolve2d с флагом "wrap".

Переделанная утилита fast_blur:
``` python
def fast_blur(img, smear_length):
    """Возвращает изображение с горизонтальным смазом заданной длины"""
    kernel_small = np.ones((1, smear_length)) / smear_length
    blurred = convolve2d(img, kernel_small, mode='same', boundary='wrap')
    return blurred
```
Результат работы этой функции идентичен частотному умножению спектров ядра и изображения.
